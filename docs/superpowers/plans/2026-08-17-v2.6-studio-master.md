# isolaTOR (FocusCast) v2.6 "Studio Master" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement v2.6 "Studio Master" enhancements including photorealistic HD background environments, adjustable edge feathering & lighting compensation, Presenter Mode (Screen-in-Camera/Split/Slide overlay), auto-scrolling smart teleprompter controls, and custom audio soundboard slots.

**Architecture:** 
- `storage.js`: Extend `DEFAULT_CONFIG` with v2.6 schema keys.
- `video-processor.js`: Integrate 5 photorealistic canvas/SVG/WebP studio presets, Gaussian edge feathering filter, screen-share capture pipeline for Presenter Mode with 3 layout templates (PiP, Split, Slide Background).
- `teleprompter.js` / `teleprompter.css`: Add font resizing (A-/A+) and `requestAnimationFrame` auto-scroll engine.
- `popup.html` / `popup.js` / `popup.css`: Add HD gallery tabs, Presenter Mode selector, teleprompter control bars, and custom audio upload slots.

**Tech Stack:** JavaScript (ES6+), WebRTC, MediaPipe SelfieSegmentation, HTML5 Canvas 2D, Web Audio API, Chrome Extensions MV3.

## Global Constraints
- Pure client-side processing, no external tracking or cloud streaming.
- Retain backwards compatibility with all existing storage profiles and hotkeys.
- Must work reliably across Google Meet, Zoom Web, and MS Teams.
